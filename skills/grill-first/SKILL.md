# Grill First

## Goal

Reach a shared, testable understanding before expensive implementation begins.

## Procedure

1. Inspect the repository and supplied documents first.
2. Separate facts already established from unresolved decisions.
3. Ask only questions whose answers materially change architecture, scope, behavior, risk, or acceptance criteria.
4. Ask one decision branch at a time when choices depend on previous answers.
5. Reflect the answer back as a concrete decision.
6. Stop questioning when the objective, boundaries, and success checks are sufficient to plan safely.

## Do not

- ask for information already present in the repo;
- turn minor implementation details into user decisions;
- keep questioning after a safe default is obvious;
- begin coding while a material product decision remains unresolved.

## Output

Produce a short decision summary containing objective, chosen approach, rejected alternatives, scope, and acceptance criteria.

# Memory Curation

## Purpose
Convert repeatable, verified lessons into reviewable operational memory.

## Candidate memory
A candidate must be useful beyond the current task and supported by evidence.

## Process
1. Extract a concise fact, rule or lesson.
2. Record source, owner, scope and review date.
3. Remove secrets, personal data and transient noise.
4. Mark confidence and validation status.
5. Obtain review when the memory changes future agent behavior.
6. Update, retire or delete memory when invalid.

## Exclusions
Do not store hidden model reasoning, unverified guesses or complete conversation transcripts as operational memory.

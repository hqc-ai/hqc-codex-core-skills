# Approval Gate

## Purpose
Pause consequential actions and present a decision-ready approval request.

## Use before
- production deployment;
- data deletion or migration;
- sending external communications;
- changing access or security controls;
- modifying financial, legal or contractual records;
- actions outside the approved plan.

## Approval request format
- proposed action;
- reason;
- affected assets;
- evidence;
- expected impact;
- rollback or alternative;
- requested decision.

Approval is specific to the presented action and does not create blanket permission.

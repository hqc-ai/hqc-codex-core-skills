# Codex Task

## Objective

Describe the outcome in observable terms.

## Current behavior

State what happens now and include evidence, errors, screenshots, routes, or commands when available.

## Desired behavior

State what must be true after the change.

## Source of truth

List the documents, files, schemas, APIs, or design decisions Codex must follow.

## Allowed scope

List features, directories, and files that may be changed.

## Protected scope

List files, systems, and behavior that must not change.

## Required investigation

State what Codex must inspect or reproduce before editing.

## Acceptance criteria

Use observable checks, not vague statements.

## Required verification

List commands, local pages, API endpoints, test cases, or manual checks.

## Git restrictions

State whether Codex may commit, push, create a branch, merge, or deploy.

## Final report

Require changed files, evidence, risks, and next action.

# Contributing

Contributions should preserve the purpose of HQC Core: small, predictable skills that improve engineering control.

A proposed skill should:

1. address a recurring agent failure mode;
2. have a clear trigger and stopping condition;
3. separate investigation from implementation;
4. avoid project-specific secrets or local paths;
5. require evidence appropriate to the task;
6. remain short enough to be loaded and followed reliably.

Do not add a skill merely because it contains useful advice. Add it when it defines a repeatable operating procedure.
